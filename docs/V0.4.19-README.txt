VISUAL CHANGES
--------------
1. HOME + PHANTOM GRID use the same new 4096x2048 RGBA organic paint material.
2. The new material is substantially more intact than V0.4.18:
   - approximately 87% fully opaque paint
   - approximately 1.5% true transparent holes
   - remaining wear is mostly subtle / semi-transparent abrasion
3. Film-grain shadow text is completely disabled on both titles.
4. Orange/cyan title corruption becomes monochrome black/white.
5. Signal corruption runs much faster (.24s and .31s cycles) but each slice is much smaller and lower-opacity.
6. Signal corruption remains beneath the physical paint layer.
7. Data-loss rectangles remain above the title at the exact existing V0.4.15 timing/frequency, now with black/white/gray treatment only.
8. Live HTML text remains the glyph mask. Font, size, wrapping and responsive geometry are not rasterized or replaced.
