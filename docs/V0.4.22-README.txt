WHY SOME LETTERS DISAPPEARED
----------------------------
This was NOT caused by the WebP format or by the DOM text itself.
The V0.4.21 CSS used a large transparent alpha material with background-repeat:no-repeat
and fixed material sizes (980/1200 px). With background-clip:text, long headings could
therefore land partly outside the painted image, while other headings could line up with
large transparent regions. Browser text selection revealed the underlying text because
the characters were still present.

V0.4.22 fixes both failure modes:
- the new material has only sparse/small transparent chips;
- the paint layer repeats, so every glyph always has material underneath it.

TEXTURE
-------
4096 x 2048 PNG RGBA
File size: 9.59 MiB
Fully transparent pixels: 0.748%
Partially transparent pixels: 10.003%

The material uses varied off-white / light-grey paint, cracks, abrasion, fine scratches,
micro-pitting and small true-alpha chips. No broad transparent islands are permitted.
