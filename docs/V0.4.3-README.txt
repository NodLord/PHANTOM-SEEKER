PHANTOM GRID
------------
Adds dynamic labels to the actual visible HEN-local axes:
- NORTH +Z
- SOUTH -Z
- EAST +X
- WEST -X
- UP +Y
- DOWN -Y

The labels follow the existing Three.js camera as the commander rotates the Grid.
The main Phantom Grid app.js is NOT modified.
