DIGITAL GLITCH
==============
The V0.4.12 horizontal cut/scanline look has been removed.

The new shared glitch on:
- HOME // EXPEDITION PHANTOM SEEKER
- GRID // PHANTOM GRID

- actual subtle deformation of the real title
- tiny scale / skew / letter-spacing errors
- broad digital data fragments instead of thin horizontal lines
- orange + cyan chromatic displacement only
- small rectangular digital corruption blocks
- film grain clipped inside the glyphs
- near-continuous low-level corruption
