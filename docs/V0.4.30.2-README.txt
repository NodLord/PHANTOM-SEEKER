BUG FIX
-------
V0.4.30.1 declared nB inside the occupied-voxel branch:

    if (...) {
      ...
    } else {
      const nB = ...
    }

but then reused nB afterwards to build the biome texture.

That causes a runtime ReferenceError:
    nB is not defined

The WebGL nebula initializer catches that error and falls back to the older
background renderer, which is why the intended Cavity Corridor topology was
not visible.

FIX
---
- A dedicated biomeNoise value is now computed before the occupancy branch.
- The occupied branch reuses biomeNoise as nB.
- The biome atlas also uses biomeNoise outside the branch.
- No visual tuning values were changed.
